📈 如何在 Termux 上安装 Matplotlib（无需编译）

在 Termux 上直接 pip install matplotlib 会触发漫长编译，这里教你绕过编译直接装。

第 1 步：从预编译源安装 Matplotlib

pip install --index-url https://nsyhykui.github.io/python_wheels_for_termux/simple/ matplotlib

第 2 步：验证

python -c "import matplotlib; print(matplotlib.__version__)"

第 3 步：无图形界面下保存图片

Termux 默认没有显示器，用 Agg 后端保存图片即可：

python -c "
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
plt.plot([1, 2, 3], [4, 5, 6])
plt.savefig('plot.png')
print('saved to plot.png')
"
⚠️ 如果报错某个 .so 找不到
把缺失的库名去掉 .so 后缀，用 pkg install 库名 安装即可。
