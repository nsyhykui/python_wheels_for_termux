📈 How to Install Matplotlib on Termux (No Compilation)

Running pip install matplotlib on Termux triggers a long build. Here is how to skip it and install directly.

Step 1: Install Matplotlib from the prebuilt index

pip install --index-url https://nsyhykui.github.io/python_wheels_for_termux/simple/ matplotlib

Step 2: Verify

python -c "import matplotlib; print(matplotlib.__version__)"

Step 3: Save figures without a display

Termux has no display by default, so save figures with the Agg backend:

python -c "
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
plt.plot([1, 2, 3], [4, 5, 6])
plt.savefig('plot.png')
print('saved to plot.png')
"
⚠️ If a .so library is reported missing
Drop the .so suffix from the missing library name and install it with pkg install <library>.
