👁️ 如何在 Termux 上安装 OpenCV（无需编译）

在 Termux 上直接 pip install opencv-python 会从源码编译 OpenCV，过程漫长且容易卡在依赖检测上。这里教你用预编译 wheel 直接装。

第 1 步：从预编译源安装 OpenCV

pip install --index-url https://nsyhykui.github.io/python_wheels_for_termux/simple/ opencv-python

pip 会自动解析并安装 NumPy 等依赖，无需手动分步操作。

第 2 步：验证

python -c "import cv2; print(cv2.__version__)"

正常会输出版本号，比如 4.12.0。

FFmpeg 版本兼容性（重要）

本源的 OpenCV wheel 基于 FFmpeg 8.x 构建，运行时需要 libavcodec.so.62。但 Termux 官方源目前已升级到 FFmpeg 9.x，因此直接安装后可能报错：

ImportError: dlopen failed: library "libavcodec.so.62" not found

目前有两种处理方式：

  • 降级 FFmpeg 到 8.x：从 Termux 历史镜像手动下载 ffmpeg_8.x_aarch64.deb 安装。注意 TUR 仓库目前只提供 ffmpeg5.1 和 ffmpeg7，没有 8.x，需要自行寻找历史包。降级可能影响其他依赖 FFmpeg 9 的软件，请自行评估。
  • 等待新版本 OpenCV：等本源基于 FFmpeg 9.x 重新构建 wheel 后再安装。在此之前，OpenCV 的视频读写功能可能不可用。
⚠️ 遇到其他 dlopen failed: library "xxx.so" not found？
把 .so 去掉，用 pkg install 装上就行：

libopenblas.so → pkg install libopenblas
