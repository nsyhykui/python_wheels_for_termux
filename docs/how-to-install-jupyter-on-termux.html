📓 How to Install Jupyter on Termux (No Compilation)

Running pip install jupyterlab on Termux triggers long builds through dependencies such as pyzmq. Here is how to skip compilation and install it directly.

Step 1: Install JupyterLab from the prebuilt index

pip install --index-url https://nsyhykui.github.io/python_wheels_for_termux/simple/ jupyterlab

If you only want the classic Notebook, replace jupyterlab with notebook.

Step 2: Start JupyterLab

jupyter lab --no-browser

The terminal prints a tokenized URL, similar to:

http://localhost:8888/lab?token=xxxxxxxx

Step 3: Open it on your phone

Copy the URL above and open it in your phone's browser. You can also open it with a command:

termux-open-url "http://localhost:8888/lab?token=xxxxxxxx"
⚠️ Getting dlopen failed: library "xxx.so" not found?
Drop the .so suffix and install the package with pkg install:

libzmq.so → pkg install libzmq
libopenblas.so → pkg install libopenblas
