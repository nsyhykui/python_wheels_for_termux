📓 如何在 Termux 上安装 Jupyter（无需编译）

在 Termux 上直接 pip install jupyterlab 会因为 pyzmq 等依赖触发漫长编译，这里教你绕过编译直接装。

第 1 步：从预编译源安装 JupyterLab

pip install --index-url https://nsyhykui.github.io/python_wheels_for_termux/simple/ jupyterlab

只需要经典版 Notebook 的话，把 jupyterlab 换成 notebook 即可。

第 2 步：启动 JupyterLab

jupyter lab --no-browser

终端会输出一个带 token 的地址，类似：

http://localhost:8888/lab?token=xxxxxxxx

第 3 步：在手机上打开

复制上面的地址，用手机浏览器打开。也可以直接用命令打开：

termux-open-url "http://localhost:8888/lab?token=xxxxxxxx"
⚠️ 遇到 dlopen failed: library "xxx.so" not found？
把 .so 去掉，用 pkg install 装上就行：

libzmq.so → pkg install libzmq
libopenblas.so → pkg install libopenblas
