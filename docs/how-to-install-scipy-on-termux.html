🔬 如何在 Termux 上安装 SciPy（无需编译）

在 Termux 上直接 pip install scipy 会触发漫长编译，这里教你绕过编译直接装。

第 1 步：安装系统依赖

pkg install libopenblas

第 2 步：从预编译源安装 SciPy

pip install --index-url https://nsyhykui.github.io/python_wheels_for_termux/simple/ scipy

第 3 步：验证

python -c "import scipy; print(scipy.__version__)"
⚠️ 如果报错 libopenblas.so not found
重新运行 pkg install libopenblas 即可。
