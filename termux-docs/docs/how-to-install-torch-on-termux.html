🔥 How to Install PyTorch on Termux (No Compilation)

Running pip install torch on Termux usually fails — PyPI has no official prebuilt wheel for Termux (Android aarch64), so pip tries to build from source, which is extremely slow and often crashes due to insufficient memory.

Step 1: Install PyTorch from the prebuilt index

pip install --index-url https://nsyhykui.github.io/python_wheels_for_termux/simple/ torch

The PyTorch wheel is large, so the download can take a while. This is normal.

Step 2: Verify

python -c "import torch; print(torch.__version__); print(torch.rand(3, 3))"

You should see a version number and a random tensor, for example:

2.x.x
tensor([[0.1234, 0.5678, 0.9012],
        [0.3456, 0.7890, 0.2345],
        [0.6789, 0.0123, 0.4567]])

FAQ

Q: Why doesn't PyTorch from the official PyPI index install?
PyTorch only publishes prebuilt wheels for Linux (manylinux) and Windows. On Termux, sys.platform is android rather than linux, so the PyPI wheels do not match.

Q: Can this PyTorch use a GPU?
No. The PyTorch in this index is the CPU build: torch.cuda.is_available() returns False and torch.version.cuda is None. It is suitable for learning and lightweight inference.

Q: import torch prints linker warnings — what should I do?
Warnings such as unused DT entry: unknown processor-specific ... (ignoring) can be safely ignored; they are Android linker notes about ELF entries and do not affect execution.

⚠️ Getting dlopen failed: library "xxx.so" not found?
Drop the .so suffix and install the package with pkg install:

libopenblas.so → pkg install libopenblas
